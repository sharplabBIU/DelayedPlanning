# Pilot sessions collected before the Study 1 preregistration (excluded from all analyses)

These ten sessions were collected on 4–5 August 2022, before Study 1 was preregistered on 26 May 2023
(https://doi.org/10.17605/OSF.IO/QS9JA). They are the "pilot data (n = 10)" whose preliminary results and power
analysis are reported in the registration (the registration's attachment `learn_to_plan_pilot_data_analyses.zip`
contains the same ten sessions). Because they were analysed before the hypotheses and analysis plan were registered,
they are **not part of any analysis reported in the manuscript**: the reported Study 1 sample consists only of the
participants recruited after preregistration (26–29 May 2023). The files are kept here, anonymised in the same way as
the main data, for completeness. `preprocess_raw_data.py` only reads files in the parent folder, so this folder is
ignored by the pipeline.
